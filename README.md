# NutriNest

NutriNest is an Android app built as part of a mobile application development task. It currently includes a splash screen, a login screen and a sign up screen.

## Features

- Splash screen shown when the app starts
- Login screen with email and password fields
- Sign up screen for creating a new account
- Navigation between the login and sign up screens

## Tech Stack

- Android Studio
- Gradle (Kotlin DSL)
- Language: Kotlin / Java (apne project ke hisaab se rakhein)

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/hadia31/NutriNest.git
   ```
2. Open the project in Android Studio.
3. Let Gradle sync finish.
4. Run the app on an emulator or a physical device.

## Project Structure

```
NutriNest/
├── app/        # Main application source code
├── gradle/     # Gradle wrapper files
└── build.gradle.kts
```
